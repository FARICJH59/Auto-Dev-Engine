# TechFusion QGPS Control Plane

Production-ready Next.js 16 application with Clerk v6 authentication, multi-tenant organization management, and comprehensive API key support.

## 🚀 Quick Start

```bash
npm install
cp .env.example .env.local
# Add your Clerk keys to .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## ✅ What's Included

- **Clerk v6 Authentication** with email + OAuth
- **Multi-Tenant Organizations** with role-based access
- **API Key Management** for programmatic access
- **Next.js 16 App Router** with React 19
- **TypeScript** throughout
- **Tailwind CSS** styling
- **Complete Documentation** in `docs/`
